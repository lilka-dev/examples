LoRa-маяк (модуль 003 LORA)
===========================

Кожні 10 секунд надсилає пакет `LILKA #N` на 868.1 МГц і виводить у послідовний порт усі прийняті пакети
(RSSI, SNR). Використовує драйвер `lilka::mod::SX126x` з бібліотеки `LilkaModules`.

Контакти модуля беруться з `lilka::config` (секція `[lora]`); змінити їх можна файлом у `/sd/.lilka/config/`.

```sh
pio run -t upload && pio device monitor
```

Перевірте, які частоти й потужності дозволені у вашій країні, і не вмикайте передачу без антени.
