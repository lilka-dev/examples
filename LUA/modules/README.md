# Модулі розширення Лілки v2

Lua-приклади для [модулів розширення](https://docs.lilka.dev/projects/keira/uk/latest/lua/reference/modules/) (потрібна Keira з модулями `gps`, `can`, `ir`, `lora`, `nrf24`, `cc1101`, `imu`, `mag`).

| Файл | Модуль | Що робить |
|---|---|---|
| [`gps.lua`](gps.lua) | 005 GPS | координати, висота, кількість супутників |
| [`can.lua`](can.lua) | 008 CAN | сніфер шини (режим `listen`, нічого не передає) |
| [`ir.lua`](ir.lua) | 002 IR | приймає сигнал пульта і повторює його кнопкою A |
| [`lora.lua`](lora.lua) | 003 LORA | чат між двома Лілками |
| [`nrf24.lua`](nrf24.lua) | 004 RF (nRF24L01+) | сканер діапазону 2.4 ГГц |
| [`cc1101.lua`](cc1101.lua) | 004 RF (CC1101) | індикатор сигналу на 433.92 МГц |
| [`imu.lua`](imu.lua) | 006 GYRO MAGNET | акселерометр і гіроскоп |
| [`mag.lua`](mag.lua) | 006 GYRO MAGNET | компас з калібруванням |

Контакти модулів беруться з налаштувань Лілки; щоб змінити їх, покладіть INI-файл у `/sd/.lilka/config/`,
наприклад:

```ini
; /sd/.lilka/config/modules.ini
[lora]
nss = 21
```

Радіомодулі передають у ефір: під'єднайте антену і перевірте, які частоти й потужності дозволені у вашій країні.
